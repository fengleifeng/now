# 《荒野卡牌》— 完整游戏策划文档

> **单一策划来源：** 本项目以本文件为唯一权威策划与数值说明；其他历史草案已归档删除，实现以本文件与代码为准。

### 《卡牌生存》(Card Survival) 复刻主轴

本工程按经典 **卡牌生存** 交互模型组织，而非传统 RPG 背包：

| 支柱 | 说明 |
|------|------|
| **万物皆卡** | 资源、工具、建筑、生物、状态均以卡牌存在；数据驱动 `data/cards.json`。 |
| **场景与手牌分离** | 当前区域「场景卡」可拾取；手牌有上限；移动不带走场景卡。 |
| **行动即时间** | 探索/移动/休息/建造推进 `DayProgress` 与天气、季节结算。 |
| **合成即规则** | 双卡拖拽与多卡自由合成由 `CombineSystem` + `combine_rules.json` 统一裁决；已学配方可在弹窗 **暂存** 到手牌（材料锁定）或 **立即** 合成；配方学习进存档。 |
| **存档分层** | 快速槽 `save_game.dat`（原子写入）；每局 `SessionId` 下 **每日自动备份最多 10 份**；**用户备份** 无上限；存档含手牌/场景/环境卡堆叠与耐久、环境再生小数、活跃效果等（`SaveFormatVersion` 2）。 |
| **逻辑与 UI 分离** | 生存与结果结算集中在 `scripts/game/CardSurvivalGame.cs`；`GameRoot` 仅负责界面与弹窗。 |
| **视觉主题** | `scripts/ui/GameTheme.cs` 与策划第十二章 RGB 对齐；侧栏/中区/右栏使用 `PanelContainer` + `StyleBoxFlat`。 |

## 一、游戏概述

| 项目 | 内容 |
|------|------|
| 游戏名称 | 卡牌生存（Card Survival 式复刻） |
| 游戏类型 | 卡牌生存策略 |
| 目标平台 | PC (Windows / macOS / Linux) |
| 引擎 | Godot 4.6 + C# |
| 游戏窗口 | **1280 × 720**（16:9），支持全屏拉伸 |
| 设计分辨率 | 1280 × 720 |
| 单局时长 | 15-30 分钟 |
| 核心循环 | 探索当前区域→拾取物品→合成→移动到新区域→推进时间 |

### 核心体验
玩家扮演一个被困荒野的幸存者。可直接「开始游戏」使用**默认幸存者**（无特质、营养基线）；也可「特质开局」选择一条特质以改变成长倾向。营养维度（蛋白质、维生素、碳水化合物、体脂倾向）随进食与每游戏日消耗变化，为后续多角色数值差异化预留空间。

### 营养与体成分（扩展）
| 字段 | 范围 | 说明 |
|------|------|------|
| 蛋白质 Protein | 0–100 | 每日自然下降；过低削弱免疫力；肉类/鱼/熟食补充。 |
| 维生素 Vitamins | 0–100 | 每日自然下降；过低削弱免疫力；浆果/草药/植物类补充。 |
| 碳水化合物 Carbohydrate | 0–100 | 每日自然下降；与饱食度联动影响体脂倾向。 |
| 体脂倾向 BodyFatIndex | 8–95 | 偏高略增移动精力消耗；进食与代谢规则可随角色模板调整。 |

卡牌可在 `cards.json` 中配置 `ProteinValue`、`VitaminValue`、`CarbValue`、`BodyFatDelta`；未配置且带 `Food` 标签时由代码按标签启发补充。

### 胜利/失败条件
- **失败**：生命值降为 0
- **目标**：存活天数越多越好，达到特定天数解锁成就
  - 存活 7 天：铜牌
  - 存活 14 天：银牌
  - 存活 30 天：金牌

### 2.5 合成弹窗

点击左侧「🔨 合成」按钮后弹出居中弹窗（标题为「合成与建造」；实现见 `CraftPopup.cs`）：

- **已学配方**每行：`材料 → 产物` 文案 + **[暂存]** + **[立即]**。  
  - **暂存**：材料在手牌中标记为「已锁定」，不可拖入场景、不可用于其它合成/食用等；手牌末尾出现 **「待合成」** 占位卡（`CardManager.StagedCombineDisplayId`），点击占位卡打开 **暂存合成** 弹窗（`StagedCombinePopup`），可查看步骤与材料，执行 **合成** 或 **取消暂存**。

## 四、玩家状态系统

### 4.1 核心属性

| 属性 | 初始值 | 上限 | 说明 |
|------|--------|------|------|
| 生命 Health | 100 | 100 | 降为0则死亡 |
| 饱食 Hunger | 100 | 100 | 降为0后每回合扣10HP |
| 精力 Energy | 100 | 100 | 探索消耗10（雾天15），移动消耗15 |
| 精神 Sanity | 100 | 100 | 夜晚/生病/遇险下降，降为0产生幻觉事件 |
| 温度 Temperature | 25°C | 0~40 | 低于0°C每回合扣5HP |

### 4.2 时间推进规则

**不再有"结束回合"按钮**，时间由操作自然推进：

| 操作 | 时间推进 | 精力消耗 | 其他消耗 |
|------|----------|----------|----------|
| 探索 | +0.05 | -10（雾天 -15） | - |
| 移动到相邻区域 | +0.10 | -15 | -3饱食 |
| 合成 | +0.02 | 0 | - |
| 拾取物品 | 0 | 0 | - |
| 食用食物 | 0 | 0 | - |

**每次时间推进时自动结算：**
- 饱食消耗：每推进0.01消耗0.5饱食（即探索一次消耗2.5，移动一次消耗5）
- 精力自然恢复：白天每推进0.01恢复0.3，夜晚每推进0.01恢复0.15
- 天数推进：进度≥1.0时+1天
- 夜晚降温：时段为Night时温度-3°C
- 耐久度：每天（进度过1.0时）所有手牌工具/建筑耐久-1

### 4.3 时间系统

| 傍晚 Evening | 0.50 ~ 0.75 | 18:00 ~ 00:00 |

## 六、合成系统

### 6.1 合成类型总览

游戏有**下列与合成相关的流程**（弹窗与手牌拖拽并存）：

| 类型 | 说明 | 示例 |
|------|------|------|
| **配方暂存** | 已学配方点「暂存」：锁定材料 + 手牌「待合成」卡；点占位卡确认后消耗时间并产出（产物可入手牌或固定栏） | 木+石→斧 |
| 即时合成（弹窗） | 已学配方点「立即」：当场消耗材料，产物进场景 | 同上 |
| 多步骤工程 | 在弹窗「工程」中多次投入材料推进进度 | 木头×6→木屋 |
| 自由合成 | 在4个槽位中自由组合尝试 | 任意组合探索未知配方 |
| 双卡拖拽合成 | 手牌中两卡叠放，由 `CombineSystem.TryCombine` 判定 | 木+石（未先学也可赌成功率） |

### 6.2 合成入口

- 点击左侧面板顶部的「🔨 合成」按钮弹出合成弹窗
- 弹窗分为：**配方（暂存/立即）** + **工程** + **自由合成**

### 6.3 合成弹窗（线框示意）

```
┌──────────────────────────────────────────────────┐
│  合成与建造                                       │
│  ──────────────────────────────────────────────  │
│  ── 配方 ──                                       │
│  ┌──────────────────────────────────────────┐    │
│  │ 木头+石头 → 石斧        [暂存] [立即]    │    │
│  │ 木头+木头 → 火堆        [暂存] [立即]    │    │
│  └──────────────────────────────────────────┘    │
│  ── 工程 ──                                       │
│  ...                                              │
└──────────────────────────────────────────────────┘
```

### 6.4 已学配方：暂存与立即

- 每行：**[暂存]**、**[立即]**；材料不足时两键禁用。  
- **暂存**：选定手牌实例并标记 `IsStagedIngredient`，手牌末尾出现「待合成」占位；**不在此时**写入配方学会（学会在「确认合成」或「立即」成功时由 `CombineSystem.LearnRuleAndResults` 执行）。  
- **立即**：当场消耗可用手牌材料，推进合成时间，产物默认进**当前场景**并学习配方。  
- **确认暂存合成**（`StagedCombinePopup` →「合成」）：按暂存顺序消耗材料 → 学习配方 → 产物：若卡表含 **`Permanent`** 或为 **`Building` 且不可拖`**，进入 **固定栏**（`SetAnchoredCard`，替换时旧卡落入当前场景）；否则加入手牌。  
- **取消暂存**：解除锁定并恢复拖拽默认值。

### 6.4a 与旧版「单按钮合成」的对照

原「每行单 [合成] 且产物进场景」的行为，对应现版的 **[立即]**。

### 6.5 多步骤合成（工程系统）

多步骤合成模拟真实的建造过程：大型项目需要多次投入同种材料，逐步推进进度，完成后获得产物。

#### 6.5.1 核心机制

```
多步骤合成流程：

1. 在合成弹窗的"多步骤工程"中选择一个工程
2. 点击[建造]按钮，消耗手牌中1个对应材料，进度+1
3. 每次建造消耗0.02时间
4. 进度达到所需次数后，工程完成，产物进入场景物品区
5. 中途可以暂停，进度保留，下次打开弹窗继续建造
```

```
🏠 木屋    木头 ██████░░░░ 3/6   [建造]

- 数字：3/6 表示已投入3个木头，还需3个
```

## 十一、存档系统

### 11.1 设计目标

- **快速槽**：主存档 `user://save_game.dat`，**原子写入**（先写 `.tmp` 再替换），避免半截 JSON。  
- **每局会话**：`SaveSystem` 维护 `SessionId`（`BeginNewPlaySession` / 读档恢复）；用于每日备份子目录名。  
- **每日自动备份**：跨游戏日时（`TimeSystem.OnDayChanged`），将**当前完整存档快照**写入 `user://saves/sessions/{SessionId}/day_XXXXXX.json`；同会话仅保留 **最新 10 份**（按日序号删最旧）。  
- **用户备份**：菜单「备份存档」→ `user://saves/user/backup_UTC时间戳[_标签].json`，**数量无上限**。  
- **存档格式版本**：`SaveFormatVersion = 2`；兼容 v1 旧档（仅字符串手牌/场景等）。

### 11.2 存档主要内容（v2）

| 键 / 区域 | 说明 |
|-----------|------|
| `SessionId` | 本局 GUID |
| 玩家数值 | 生命/饱食/口渴/精力/精神/免疫、温度、各上限、营养与体脂、技能等级、特质列表等 |
| 时间与天气 | `CurrentDay`、`DayProgress`、`Season`、`Weather` |
| `HandDetailed` | 每张手牌 `Id` + `Stack` + `Durability` |
| `ScenesDetailed` | 各区域场景卡列表（同上结构） |
| `EnvironmentsDetailed` | 各区域环境卡列表 |
| `EnvRegen` | 环境再生累积小数（键为 `地区|卡Id`） |
| `ActiveEffects` | `EffectId`、`RemainingTurns`、`Intensity` |
| `Projects` / `Completed` / `Learned` | 工程进度、已完成建筑、已学配方 |
| `CurrentLocation` | 与 `MapSystem` 一致 |

读档顺序要点：`ClearRuntimeCards` → `MapSystem.PrepareWorldForSaveLoad` → 恢复时间与位置 → 手牌/场景/环境 → 无环境数据则 `RestoreDefaultEnvironmentIfEmpty()` → 再生与效果 → `PlayerSystem.SetTraits` 后再覆盖数值字段（避免特质重置覆盖已存属性）。

### 11.3 与策划 JSON 的关系

- `data/cards.json` 等仍为卡表权威来源；存档中的实例字段以运行时为准。  
- `data/game_settings.json` + `GameSettings` 自举：各操作默认耗时等可调。

### 11.4 旧版 JSON 示例（v1 概念，已演进）

以下为 v1 思路示意，**当前实现请以 v2 与代码为准**：

```json
{
	"SaveFormatVersion": 1,
	"CurrentDay": 1,
	"DayProgress": 0.25,
	"Hand": ["wood", "stone"],
	"Scenes": { "forest": ["rabbit"] }
}
```

## 十五、趣味玩法扩展（已实现）

以下为在核心循环之上增加的短决策、高风险回报与小惊喜，均已接入主流程（`GameRoot` / `StatusPanel` / `CardManager` / `EffectSystem`）。

### 15.1 晴天「荒野馈赠」

- **触发：** 当前天气为晴天时，每次探索在常规 1 次掉落之后，有 **25%** 概率再掉 **1** 张当前区域探索池内的随机卡。
- **体验：** 鼓励在好天气多出门，与暴雨、雾天的惩罚形成对照。

### 15.2 雾天探索代价

- **规则：** 雾天时单次探索精力消耗由 **10** 提高到 **15**（与策划文档天气表一致）。
- **界面：** 区域栏探索按钮文案随天气更新。

### 15.3 磨刀（维护工具）

- **入口：** 左侧状态栏在「休息」下方显示 **磨刀** 按钮。
- **条件：** 手牌中存在 **耐久未满** 的 `Tool` 或 `Weapon`（耐久以 `data/cards.json` 中该卡默认耐久为上限）。
- **消耗：** **8** 点精力，推进时间 **0.02**。
- **效果：** 将上述第一张可修工具 **+1** 耐久（不超过该卡默认上限）。
- **设计意图：** 在「弃牌换新」与「扛过今晚」之间做资源博弈，延长单张关键武器寿命。

### 15.4 夜仪·驱赶厄运

- **入口：** 左侧状态栏 **夜仪** 按钮（仅当条件满足时显示）。
- **条件（同时满足）：** 当前为 **夜晚**；手牌中至少有 **1** 张 `campfire`（火堆）与 **1** 张 `herb`（草药）；且玩家 **精神 < 50** 或 **身上存在至少一种疾病**。
- **消耗：** **1** 张草药（火堆不消耗），时间 **+0.05**，饱食 **-3**。
- **效果：** 若存在疾病，**移除一个**疾病效果；并 **+20** 精神。
- **设计意图：** 把「火堆 + 草药」从纯合成链里拉出一条仪式向的叙事操作，给低精神/带病生存一条主动出路。
