# 《荒野卡牌》— 完整游戏策划文档

---

## 一、游戏概述

| 项目 | 内容 |
|------|------|
| 游戏名称 | 荒野卡牌（Wild Card Survival） |
| 游戏类型 | 卡牌生存策略 |
| 目标平台 | PC (Windows / macOS / Linux) |
| 引擎 | Godot 4.6 + C# |
| 游戏窗口 | **1280 × 720**（16:9），支持全屏拉伸 |
| 设计分辨率 | 1280 × 720 |
| 单局时长 | 15-30 分钟 |
| 核心循环 | 探索当前区域→拾取物品→合成→移动到新区域→推进时间 |

### 核心体验
玩家扮演一个被困荒野的幸存者，在地图上的不同区域间移动。每个区域有独特的资源和交互。通过卡牌操作探索当前区域、从场景中拾取物品、在合成弹窗中组合多物品。管理饥饿、寒冷和体力，在荒野中尽可能存活更多天数。

### 胜利/失败条件
- **失败**：生命值降为 0
- **目标**：存活天数越多越好，达到特定天数解锁成就
  - 存活 7 天：铜牌
  - 存活 14 天：银牌
  - 存活 30 天：金牌

## 四、玩家状态系统

### 4.1 核心属性

| 属性 | 初始值 | 上限 | 说明 |
|------|--------|------|------|
| 生命 Health | 100 | 100 | 降为0则死亡 |
| 饱食 Hunger | 100 | 100 | 降为0后每回合扣10HP |
| 精力 Energy | 100 | 100 | 探索消耗10，移动消耗15 |
| 精神 Sanity | 100 | 100 | 夜晚/生病/遇险下降，降为0产生幻觉事件 |
| 温度 Temperature | 25°C | 0~40 | 低于0°C每回合扣5HP |

### 4.2 时间推进规则

**不再有"结束回合"按钮**，时间由操作自然推进：

| 操作 | 时间推进 | 精力消耗 | 其他消耗 |
|------|----------|----------|----------|
| 探索 | +0.05 | -10 | - |
| 移动到相邻区域 | +0.10 | -15 | -3饱食 |
| 合成 | +0.02 | 0 | - |
| 拾取物品 | 0 | 0 | - |
| 食用食物 | 0 | 0 | - |

**每次时间推进时自动结算：**
- 饱食消耗：每推进0.01消耗0.5饱食（即探索一次消耗2.5，移动一次消耗5）
- 精力自然恢复：白天每推进0.01恢复0.3，夜晚每推进0.01恢复0.15
- 天数推进：进度≥1.0时+1天
- 夜晚降温：时段为Night时温度-3°C
- 耐久度：每天（进度过1.0时）所有手牌工具/建筑耐久-1

### 4.3 时间系统

| 时段 | 进度范围 | 游戏时间 |
|------|----------|----------|
| 早晨 Morning | 0.00 ~ 0.25 | 06:00 ~ 12:00 |
| 中午 Noon | 0.25 ~ 0.50 | 12:00 ~ 18:00 |
| 傍晚 Evening | 0.50 ~ 0.75 | 18:00 ~ 00:00 |
| 夜晚 Night | 0.75 ~ 1.00 | 00:00 ~ 06:00 |

### 4.4 天气系统

每天切换天气：

| 天气 | 概率 | 效果 |
|------|------|------|
| 晴天 Sunny | 50% | 无特殊效果 |
| 雨天 Rainy | 20% | 火堆耐久额外-1 |
| 暴雨 Stormy | 10% | 无庇护所温度-5，火堆耐久-2 |
| 雾天 Foggy | 10% | 探索消耗精力+5 |
| 雪天 Snowy | 10% | 温度-8，无庇护所温度额外-3 |

### 6.1 合成类型总览

游戏有**三种合成类型**：

| 类型 | 说明 | 示例 |
|------|------|------|
| 即时合成 | 放入材料立即出结果 | 木头+石头→石斧 |
| 多步骤合成 | 需要多次添加同种材料，逐步推进进度 | 木头×6→木屋（需操作6次） |
| 自由合成 | 在4个槽位中自由组合尝试 | 任意组合探索未知配方 |

### 6.2 合成入口

- 点击左侧面板顶部的「🔨 合成」按钮弹出合成弹窗
- 弹窗分为三部分：**已学会配方** + **多步骤工程** + **自由合成**

### 6.4 即时合成（已学会配方）

玩家在游戏中首次成功合成某个配方后，该配方被"学会"，记录在配方列表中。

- 每行显示：图标 + 产物名 + 材料列表 + [合成]按钮
- 材料不足时[合成]按钮灰色不可点击
- 材料充足时[合成]按钮高亮可点击
- 点击[合成]：消耗手牌中对应材料，产物进入场景物品区
- 列表可滚动

### 6.5 多步骤合成（工程系统）

多步骤合成模拟真实的建造过程：大型项目需要多次投入同种材料，逐步推进进度，完成后获得产物。

#### 6.5.1 核心机制

```
多步骤合成流程：

1. 在合成弹窗的"多步骤工程"中选择一个工程
2. 点击[建造]按钮，消耗手牌中1个对应材料，进度+1
3. 每次建造消耗0.02时间
4. 进度达到所需次数后，工程完成，产物进入场景物品区
5. 中途可以暂停，进度保留，下次打开弹窗继续建造
```

#### 6.5.2 工程进度显示

```
🏠 木屋    木头 ██████░░░░ 3/6   [建造]

- 图标+名称：工程名
- 材料名：需要的材料类型
- 进度条：已完成/总次数（10格可视化）
- 数字：3/6 表示已投入3个木头，还需3个
- [建造]按钮：手牌中有对应材料时可点击
```

#### 6.5.3 工程规则

| 规则 | 说明 |
|------|------|
| 进度保留 | 中途关闭弹窗，进度不丢失，下次可继续 |
| 每次投入 | 消耗手牌中1个对应材料，进度+1 |
| 时间消耗 | 每次投入消耗0.02时间 |
| 完成产出 | 进度满后产物进入场景物品区 |
| 放弃工程 | 可点击[放弃]取消工程，已投入材料不退还 |
| 同时进行 | 最多同时进行**3个**工程 |
| 解锁条件 | 部分工程需要先学会特定即时配方才解锁 |

### 6.6 自由合成

在弹窗底部的4个槽位中自由放入卡牌：

```
┌────┐ ┌────┐ ┌────┐ ┌────┐  ┌────┐
│    │ │    │ │    │ │    │→ │ ?  │
└────┘ └────┘ └────┘ └────┘  └────┘
		[ 合成 ]  [ 清空 ]
```

- 从手牌拖拽卡牌到槽位
- 放入2+个材料后自动预览结果
- 合成成功：产物进入场景物品区，槽位清空
- 合成失败：材料仍在槽位中
- 清空：材料退回手牌

### 6.9 配方学会机制

- 首次成功合成某个即时配方后，该配方自动加入"已学会"列表
- 学会的配方显示在合成弹窗上半部分
- 已学会配方可一键合成（无需拖拽），前提是手牌中有足够材料
- 多步骤工程无需"学会"，但部分工程有**解锁条件**（需先学会特定即时配方）
- 配方学会状态和工程进度保存在存档中

## 七、交互系统

### 7.1 操作方式

| 操作 | 触发条件 | 效果 |
|------|----------|------|
| 点击场景物品 | 点击场景中的卡牌 | 拾取到手中 |
| 点击手牌(食物) | 点击有 FoodValue 的卡 | 直接食用，消耗卡牌 |
| 点击手牌(草药) | 点击有 HealValue 的卡 | 直接使用，消耗卡牌 |
| 点击手牌(其他) | 点击无食用/治疗值的卡 | 日志显示卡牌描述 |
| 拖拽手牌→场景区 | 拖动>15px，落在场景物品区 | 将手牌放入场景 |
| 点击[🔍探索] | 区域交互按钮 | 消耗10精力，从探索池抽1张卡到场景 |
| 点击[前往xx] | 区域交互按钮 | 消耗15精力，移动到相邻区域 |
| 点击[🔨合成] | 左侧面板按钮 | 弹出合成弹窗 |
| 点击[🗺地图] | 右上角按钮 | 弹出地图弹窗 |
| 点击[菜单] | 左侧面板按钮 | 弹出菜单（保存/退出） |

### 7.2 物品流转规则

```
当前区域 ──探索──→ 场景物品区 ──点击──→ 手牌
					   ↑                    │
				  合成弹窗 ──成功──→ 场景物品区
					   ↑                    │
				  手牌 ──拖入──→ 合成弹窗    │
				  手牌 ──配方合成──→ 场景物品区
										  │
							  手牌 ──拖到场景──→ 场景物品区
```

### 7.3 手牌规则

| 规则 | 数值 |
|------|------|
| 初始手牌 | 4张（从当前区域探索池中随机抽取） |
| 手牌上限 | 8张 |
| 超出上限 | 最旧的卡牌自动丢弃 |
| 探索产出 | 先进入场景物品区，需手动拾取 |
| 移动时 | 手牌跟随玩家，场景物品留在原区域 |
